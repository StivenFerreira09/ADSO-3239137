# Página pública de Costumes

## Descripción

Esta carpeta contiene la página pública de Costumes, diseñada para presentar de forma clara las principales funciones del sistema de gestión de alquiler de trajes y disfraces.

La página es estática y funciona de manera independiente de la aplicación administrativa.

## Tecnologías

- HTML5
- CSS3
- Nginx para servir la página mediante Docker
